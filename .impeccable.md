## Design Context

### Users
Solo indie iOS developer (the owner) designing App Store screenshot sets for his apps.
Desktop browser, focused work sessions, often at night. Wants AppScreens.com-level output
without the subscription. The job: configure screens fast (background, device, text,
screenshot), then export a validated ZIP.

### Brand Personality
Précis, dense, confiant. Un instrument de précision, pas un dashboard : l'interface flotte
au-dessus du travail et s'efface derrière les maquettes. French UI.

### Aesthetic Direction (v3, 2026-07)
Monochrome ultra-sobre, classe Linear/Vercel : graphite chaud quasi neutre en OKLCH
(chroma ≤ 0.004), stage toujours le plus sombre, vignette discrète. Accent **blanc**
(foreground) pour les actions primaires ; rouge `#d71921` (`export`) réservé au SEUL
bouton Export — jamais pour la sélection ni l'état actif. Focus ring neutre, aucun bleu.
Structure en **réduction maximale** : une barre unique h-11 en haut, drawers calques /
propriétés rétractables superposés au stage (⌘⇧L / ⌘⇧P), filmstrip d'écrans fine (~80px),
stage maximal. Typographie : **Geist** unique — hiérarchie par poids et taille ; labels
`.caps-label` (Geist Sans caps 10px discrets), valeurs numériques en **Geist Mono**
tabulaire. Rayons : îlots/modals 8px, contrôles 6px. Ombres discrètes réservées aux
îlots et overlays. z-index : 5 niveaux nommés (`--z-chrome/overlay/modal/popover/toast`).
Motion : ease-out expo 120–200ms, transform/opacity only.
Light theme : même structure, neutres clairs, accent noir, export rouge identique.
Patterns conservés : ⌘K command palette, scrubbable numeric fields, toasts, shortcuts overlay (?).

### Design Principles
1. Content pops, chrome recule : le stage est toujours plus sombre que les artboards ; le chrome se réduit à une barre et des drawers.
2. Un seul rouge, un seul endroit : `export` ne sert qu'au bouton Exporter ; l'actif/sélection est neutre (bordure claire).
3. Monochrome discipliné : neutres graphite + blanc ; aucune couleur décorative, focus neutre.
4. Labels en `.caps-label` 10px discrets ; valeurs en Geist Mono tabulaire.
5. Every control shows its state: hover, active, disabled, focus-visible.
6. French everywhere, terse labels, no decorative copy.
7. Depth is earned: borders and luminance steps for static surfaces; shadows only when floating.
