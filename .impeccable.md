## Design Context

### Users
Solo indie iOS developer (the owner) designing App Store screenshot sets for his apps.
Desktop browser, focused work sessions, often at night. Wants AppScreens.com-level output
without the subscription. The job: configure screens fast (background, device, text,
screenshot), then export a validated ZIP.

### Brand Personality
Précis, dense, confiant. Un instrument de précision, pas un dashboard : l'interface flotte
au-dessus du travail et s'efface derrière les maquettes. French UI.

### Aesthetic Direction (v2, 2026)
Dark editor chrome as **floating islands** over a full-bleed stage (Figma UI3 / Linear /
Raycast class). Warm graphite in OKLCH tinted toward the brand hue; stage always darkest,
with a subtle warm vignette. One red accent (#d71921) reserved for the export CTA, the
active artboard and the active tool. Restrained blue for focus only. Typography:
**Archivo** (UI) + **Chivo Mono** (labels ALL CAPS 10px, tabular values). Real elevation
model: flat static surfaces, soft shadows only on islands, menus and modals. Radius ≤ 12px
on controls and islands. Motion: ease-out expo 120–200ms, transform/opacity only.
Light theme stays available, same structure. Patterns: ⌘K command palette, scrubbable
numeric fields, toasts, shortcuts overlay (?).

### Design Principles
1. Content pops, chrome floats: the stage is always darker than the artboards; panels are islands.
2. One accent, used rarely: red means "export" and "active", nothing else.
3. Labels are Chivo Mono ALL CAPS 10px; values are tabular-nums.
4. Every control shows its state: hover, active, disabled, focus-visible.
5. French everywhere, terse labels, no decorative copy.
6. Depth is earned: borders and luminance steps for static surfaces; shadows only when floating.
