## Design Context

### Users
Solo indie iOS developer (the owner) designing App Store screenshot sets for his apps.
Desktop browser, focused work sessions, often at night. Wants AppScreens.com-level output
without the subscription. The job: configure screens fast (background, device, text,
screenshot), then export a validated ZIP.

### Brand Personality
Precis, dense, confiant. A pro tool, not a landing page. The interface disappears behind
the content; the screenshots being designed are the color. French UI.

### Aesthetic Direction
Dark editor chrome (Figma-class), warm-neutral grays, no blue-slate. One red accent
(#d71921) reserved for the primary action and active state. Typography: Space Grotesk
(UI) + Space Mono (labels, numerics, ALL CAPS 10px). Flat surfaces, 1px hairline borders,
radius <= 8px on controls. The canvas stage is distinctly darker than panels so white
artboards read instantly. Light theme stays available, same structure.

### Design Principles
1. Content pops, chrome recedes: the stage is always darker than the artboards.
2. One accent, used rarely: red means "export" and "active", nothing else.
3. Labels are Space Mono ALL CAPS 10px; values are tabular-nums.
4. Every control shows its state: hover, active, disabled, focus-visible.
5. French everywhere, terse labels, no decorative copy.
