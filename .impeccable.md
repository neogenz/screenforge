## Design Context

### Users

Solo indie iOS developer (the owner) designing App Store screenshot sets for his apps.
Desktop browser, focused work sessions, often at night. Wants AppScreens.com-level output
without the subscription. The job: import simulator screenshots, compose a coherent set of
up to ten screens, then export a validated ZIP.

### Brand Personality

Précis, dense, confiant. Un instrument de précision, pas un dashboard : l'interface flotte
au-dessus du travail et s'efface derrière les maquettes. French UI.

### Aesthetic Direction (v7, 2026-08, coss ui)

**coss neutral, un seul marqueur d'état.** La palette est `@coss/colors-neutral`, installée par
le CLI et jamais re-thémée : toutes les surfaces du chrome restent à chroma 0 par construction,
pas par discipline. Le citron `--color-marker` (extension `design-system/tokens.css`) est réservé
à « vous êtes ici » : écran courant, calque sélectionné, outil actif et focus. Il ne colore
jamais une action ni le bord d'un artboard — il n'a pas de nom dans le contrat shadcn et n'en
prend pas, `accent` restant le lavis de survol coss. L'action primaire (Exporter) est `--primary`
coss tel quel : neutral-800 plein sur fond clair, neutral-100 sur fond sombre — le blanc-sur-
graphite d'avant sans rien re-thémer. `--color-destructive` ne sert qu'au destructif.

**Dark reste le thème par défaut**, posé sur `<html>` au boot (`document.documentElement.
classList.toggle('dark', …)`) ; il n'y a plus de classe `.light`, l'absence de `.dark` est le
clair — la convention de coss et de Base UI, adoptée telle quelle plutôt que retenue de v6.
Le clair tient sur **deux niveaux, pas cinq** : scène `oklch(0.965 0 0)`, cartes `oklch(1 0 0)`,
l'ombre de la carte fait la séparation.

**Un seul rayon amont, une chaîne fermée qui en dérive.** `--radius: 0.625rem` (10px) ; `sm` 6px,
`md` 8px, `lg` 10px (boutons, champs), `xl` 14px, `2xl` 18px (îlots, popovers, modales). Pas de
pilule : boutons et badges restent en `rounded-lg`, `rounded-full` est réservé à ce qui est
réellement circulaire (thumb de switch, spinner, poignée de défilement).

**Tailles coss.** Contrôles en `h-9`/`h-8`/`h-7` (rendu resserré au bureau via `sm:`), icônes en
`size-9`/`size-8`/`size-7`, `data-slot` sur chaque partie de chaque composant. Les échelles
restent fermées et sont mesurées sur le DOM peuplé par `pnpm run audit:scale` plutôt que
comparées à une liste blanche — coss ne laisse plus une taille littérale visible dans
`index.css`.

**Typographie : Inter variable, auto-hébergée, une seule famille.** `@fontsource-variable/inter`,
importée directement dans `index.css` (plus de `<link>`, plus de bascule `media="print"`).
Corps de base 14px, tracking 0, hiérarchie par poids et taille. Valeurs numériques en
`.tabular` — Inter a des chiffres tabulaires natifs. Geist Mono (auto-hébergée aussi) habille
`kbd`/`code`, choix par défaut de coss.

**Structure : réduction maximale, inchangée.** Une barre unique en haut, drawers calques /
propriétés rétractables superposés au stage (⌘⇧L / ⌘⇧P) qui **épousent leur contenu**, filmstrip
d'écrans, stage maximal. Barre contextuelle près de la sélection quand le drawer Propriétés est
fermé. La surface flottante elle-même est le composant `Island` (coque `Card` coss), plus une
classe CSS séparée avec son propre calcul de retrait.

z-index : 6 niveaux nommés (`--z-stage-veil/chrome/overlay/modal/popover/toast`), dans
`design-system/tokens.css`. Motion : 100 % CSS, `--duration-fast/base/slow` + `--ease-out`,
120–260ms, transform/opacity only, `--ease-settle` comme seul ressort (`linear()` natif, 6 % de
dépassement) ; les entrées/sorties des surfaces coss suivent `data-starting-style`/
`data-ending-style` de Base UI. Patterns conservés : ⌘K command palette (coss `command`,
habillage oa), champs numériques scrubbables (`NumberFieldScrubArea` de Base UI), toasts
(sonner), shortcuts overlay (?).

### Design Principles

1. Content pops, chrome recule : le stage est toujours plus sombre que les artboards ; le chrome se réduit à une barre et des drawers.
2. Aucune teinte décorative dans le chrome : l'action primaire est un blanc plein et rien de chromatique ne touche les artboards.
3. Monochrome discipliné : surfaces à chroma 0 ; le seul citron marque l'état courant et le focus.
4. Libellés en casse normale (`.field-label`), jamais de capitales trackées ; valeurs en `.tabular`.
5. Every control shows its state: hover, active, disabled, focus-visible, loading, invalid.
6. French everywhere, terse labels, no decorative copy.
7. Depth is earned: luminance steps first, borders second, shadows only when floating.
8. L'unité de travail est la planche de dix écrans, pas l'écran : tout geste répétitif dix fois doit avoir un équivalent « pour tous les écrans ».
